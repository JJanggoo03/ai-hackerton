# 취업·학습 대화와 기억

START-SERVER.cmd 또는 npm start로 웹 서버와 Python 도구 서버를 함께 실행합니다. node server/index.js 직접 실행은 고용24 도구와 대화 맥락 게이트웨이를 시작하지 않습니다.

- 일반 답변과 취업 질문은 같은 도구 사용 가능한 대화 엔진을 사용합니다. JSON 계획 생성과 짧은 분류 호출은 제외합니다.
- 고용24 도구는 실제 결과를 사용하며 출처는 답변 아래에 표시합니다.
- MySQL assistant_conversations 테이블에 최근 100개 메시지(50번 질문/답변), 사용자 발언에서 추출한 기억, 진행 중인 스펙 평가 상태를 저장합니다.
- 모델에는 최근 12개 메시지의 일부와 최대 12개 사용자 발언을 전달합니다. 모든 과거 내용을 무제한 기억하지 않습니다.
- 대화 ID는 서버가 생성하고 DB 세션에 저장합니다. 새로고침·서버 재시작 후 같은 로그인 세션이면 복원됩니다. 기존 시연 계정을 공유하므로 다른 브라우저/로그아웃 후 이전 대화를 자동으로 찾지 않습니다.
- 새 대화는 새 ID로 시작하며 이전 기록은 DB에 남습니다. 현재 UI는 활성 대화의 이전 기록만 표시합니다.
- API: GET /api/assistant/history, POST /api/assistant/reset. 기존 인증과 CSRF 검증을 적용합니다.
- 파일: server/conversation-store.js, integrations/career-server/study_chat_api.py, integrations/career-server/job_assistant.py.

2026-11-06 챗봇 개선
- 통합 실행에서는 Node가 보관함/GitHub 자료와 대화 상태를 Python 도구 서버에 전달합니다.
- 고용24 요청을 별도 정부24 탐색으로 우회하지 않습니다.
- 명시적인 훈련과정/취업역량 프로그램 검색은 grounded_programs.py에서 실제 API 결과로 작성합니다.
- 기관·일정·상세 링크 필드를 읽고 종료된 과정은 제외합니다. 전국 검색이며 지역별 맞춤 순위가 아닙니다.
- 분야 검색어를 다음 질문에 이어서 사용하고, 추가한 사용자 스펙도 이전 입력과 함께 비교합니다.
- 모델의 일반 상담과 자료 설명 기능은 유지합니다. 한국어 자동 재작성은 사용하지 않습니다.
- 검증: Python 검사 20개, Node 관련 검사 12개 통과. 실제 고용24 검색/후속 검색/프로그램 조회 및 MySQL 대화 저장 확인.
- 기존 직접 Ollama 경로의 career-answer 테스트 실패 2건은 이번 수정 대상에 포함하지 않았습니다.
